# Documentation Structure

This directory contains technical documentation and archived files for the DripOut project.

## Active Documentation

- **`/APPLE_SIGNIN_COMPLIANCE.md`** - Apple Sign-In compliance documentation (reference only)

## Archived Documentation

The `/archive/` directory contains consolidated documentation that has been replaced by:
- **Root `/README.md`** - Public-facing app overview  
- **Root `/TECHNICAL_DOCUMENTATION.md`** - Comprehensive technical documentation

### Archived Files
- `CLAUDE.md` - Previous technical instructions (consolidated into TECHNICAL_DOCUMENTATION.md)
- `DEVELOPMENT_LOG.md` - Development history (consolidated into TECHNICAL_DOCUMENTATION.md)
- `DRIPOUT_ARCHITECTURE.md` - Architecture overview (consolidated into TECHNICAL_DOCUMENTATION.md)
- `error_fixes.md` - Technical debt list (consolidated into TECHNICAL_DOCUMENTATION.md)
- `SESSION_MANAGEMENT_IMPLEMENTATION.md` - Session management details (consolidated into TECHNICAL_DOCUMENTATION.md)
- `todo.md` - Development todos (consolidated into TECHNICAL_DOCUMENTATION.md)
- `notes.txt` - Miscellaneous development notes (consolidated into TECHNICAL_DOCUMENTATION.md)

## Documentation Guidelines

All new documentation should be added to the main `TECHNICAL_DOCUMENTATION.md` file to maintain a single source of truth. This archive is maintained for historical reference only.
